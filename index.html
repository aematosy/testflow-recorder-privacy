TestFlow Recorder Privacy Policy

Last updated: October 12, 2026

Overview

TestFlow Recorder is a browser extension designed for software testing. It allows users to record user-initiated interactions with web applications, inspect UI elements, generate element locators, create assertions, replay recorded test flows, and generate testing evidence.

Data processed by the extension

During an explicitly initiated testing session, TestFlow Recorder may process information required to represent the test flow, including user interactions, page URLs and titles, DOM element metadata, locator information, values entered into test fields, assertions, screenshots, and execution results.

Authentication or other sensitive input fields are identified as sensitive when possible. Recorded password values are redacted, and sensitive values required for replay must be supplied by the user at execution time.

Local storage

Recorded test flows, extension state, execution configuration, locator information, screenshots, and execution results may be stored locally in the user's browser using Chrome extension storage and IndexedDB.

Data transmission

TestFlow Recorder does not sell user data and does not transmit recorded test data to external servers operated by the developer. The extension does not use recorded information for advertising, profiling, creditworthiness evaluation, or purposes unrelated to software testing.

Exported data

Users may explicitly export testing artifacts such as recorded flow JSON, ZIP files, and HTML execution reports. Export occurs only when initiated by the user. Users are responsible for how exported files are subsequently stored or shared.

Browser permissions

TestFlow Recorder requires browser permissions necessary to record and replay tests, inspect application elements, preserve testing context across navigation, support iframe and Shadow DOM scenarios, manage isolated test sessions, and export testing artifacts.

Data retention and deletion

Testing data remains under the user's control. Users can clear recordings through the extension and can remove locally stored extension data by removing the extension or clearing its storage.

Third parties

TestFlow Recorder does not sell or transfer recorded user data to third parties except where required by law or otherwise permitted by applicable Chrome Web Store policies.

Changes to this policy

This privacy policy may be updated when TestFlow Recorder functionality or its data practices change.
